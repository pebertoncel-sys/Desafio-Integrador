# Desafio Integrador

Projeto avaliativo desenvolvido em Java para registrar pedidos de uma lanchonete.

## Primeira parte

A solução em `PrimeiraParte/RegistroPedidos.java` permite cadastrar vários pedidos, validar valores maiores que zero e exibir ao final a quantidade de pedidos, o total vendido, o ticket médio, a maior compra e a menor compra.

## Desafios opcionais

Cada desafio foi colocado em uma pasta separada:

- `Desafio1/ComprasAcimaDe50.java`: informa quantas compras tiveram valor superior a R$ 50,00.
- `Desafio2/MaiorCompra.java`: exibe o nome do cliente que realizou a maior compra.
- `Desafio3/MediaAcimaDe30.java`: calcula a média somente das compras acima de R$ 30,00.
- `Desafio4/MenuPedidos.java`: adiciona um menu inicial para cadastrar pedidos, exibir o relatório e encerrar o sistema.
- `Desafio5/MetaVendas.java`: exibe a mensagem “Meta atingida!” quando o total vendido supera R$ 500,00.

Para executar qualquer solução:

```bash
cd NomeDaPasta
javac NomeDoArquivo.java
java NomeDaClasse
```
