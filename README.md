# Desafio Integrador

Projeto avaliativo desenvolvido em Java para registrar pedidos de uma lanchonete.

## Primeira parte

A solução em `PrimeiraParte/RegistroPedidos.java` permite cadastrar vários pedidos, validar valores maiores que zero e exibir ao final a quantidade de pedidos, o total vendido, o ticket médio, a maior compra e a menor compra.

Para executar:

```bash
cd PrimeiraParte
javac RegistroPedidos.java
java RegistroPedidos
```
